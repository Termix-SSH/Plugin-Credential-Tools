## Overview

Credential Tools adds key helpers to the credential editor: generate a key pair, find out a key's type, get the public key from a private key, check that a pair matches and copy a public key to a host.

Read the [docs](https://docs.termix.site/plugins/credential-tools) to set it up and use it.

<br />

## Features

- Generate SSH key pairs
- Detect a key's type and get its public key
- Check that a public and private key match
- Deploy a saved key to a host's authorized keys

Problems with Termix itself (login, hosts, credentials, sharing, sync) go in the [Termix repo](https://github.com/Termix-SSH/Termix/issues/new/choose). Not sure where it goes? Open it there and it will be moved.

Add as much detail as you can, in English if possible. For questions, join the [Discord](https://discord.gg/jVQGdvHDrf) server.
